# DOTA MIND — Mini App

Telegram Mini App для бота [@dota_mind_coach_bot](https://t.me/dota_mind_coach_bot): персональный ИИ-тренер по Dota 2.

- Разбор матчей на герое: винрейт, главная проблема и советы, сравнение GPM, XPM, добиваний и урона с другими игроками
- Контрпики и популярные сборки героев
- Последние матчи с оценкой фарма

Статистика — [OpenDota API](https://docs.opendota.com/). Файл `index.html` собирается из исходников основного проекта (`python tools/build_webapp.py`).

DOTA MIND не связан с Valve. Dota 2 — товарный знак Valve Corporation.
